# Test Strategy

## Approach
This project follows the **Page Object Model (POM)** pattern to ensure test maintainability and reusability. 

## Testing Scope
- **Smoke Tests:** Critical path validation for core functionality.
- **Regression:** Ensuring new changes do not break existing features.
- **Cross-Browser:** Validation across Chrome, Firefox, and WebKit.

## Execution
Tests are automated using Playwright, ensuring high-speed execution and reliable results.
