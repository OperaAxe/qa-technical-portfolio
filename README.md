# QA Technical Portfolio

This repository serves as a professional showcase of automated testing frameworks and technical documentation. My goal is to bridge the gap between robust software quality assurance and clear, actionable technical communication.

# 🛠 Tech Stack

* **Automation:** Playwright (TypeScript)
* **Documentation:** Markdown / Docs-as-Code
* **Version Control:** Git & GitHub

# 📂 Navigation

* **Setup Guide** – How to install and run the test suite.
* **Bug Reports** – Examples of professional bug documentation.
* **Test Strategy** – (Coming soon) High-level testing approach.

# 🎯 Objective

This project demonstrates:

1. **Automated Testing:** Implementation of reliable, scalable end-to-end tests.
2. **Technical Writing:** Ability to translate technical processes into easy-to-follow documentation for stakeholders.
